## 一、背景介绍

​	本人开发此网站从2024年7月7日开始规划。但是从2024年末开始，要考研，又要开发，又要带带新生，所以开发进度极慢，现在开发功能模块仅**20**个不到，许多前端和后端的细节处理还有很大问题，部分功能实现可能甚至需要实现重构处理。

## 二、网站简单介绍

​	可以通过**[网站介绍](https://www.byteoj.com/introduction)**部分直接查看，内容大概有**3000**多字。

​	**补充说明：**本网站暴露接口共**109**个小接口。后端主要使用了**注册器模式、适配器模式、单例模式**等设计模式，后端目前主要配备了**Redis、MySQL**，使用**Nginx**部署前端，**Docker**部署后端，代码沙箱由**Go**实现。网站用户人数目前未**127**个。

​	**预计调整：** 有时间便会开始引入**RocketMQ**，同时会开始尝试引入**MongoDB（如果服务器撑得住）**，**Elaticsearch** 完全带不动，不用尝试，至少得**16核**起步。
